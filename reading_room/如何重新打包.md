# 如何重新打包

`src/` 是源码，`reading_room.toolpkg` 是成品。改了源码要重新出一个包，导入手机的才是新界面。

## 需要什么

- Node.js（用 `npx` 跑 TypeScript）
- **Operit 官方的类型定义**（`types/*.d.ts`，从 Operit 项目里取）。本仓库不带这些文件。

## 步骤

```
reading_room/
├── src/            源码
├── types/          ← 自己放进来（Operit 官方 types）
├── manifest.json
└── dist/           编译产物
```

1. 把官方 types 放到 `types/` 下，`src/ui/*.ts` 里那句 `import type { … } from "../../types/compose-dsl"`
   就能解析到了。
2. 编译：

   ```
   npx -y -p typescript@5.4.5 tsc --noEmit -p tsconfig.json   # 先类型检查
   npx -y -p typescript@5.4.5 tsc -p tsconfig.json            # 再编译
   ```

3. 打包成 `.toolpkg`：**三个文件，不加目录项**

   ```
   manifest.json
   main.js                  ← 来自 dist/main.js
   ui/reading_room.ui.js    ← 来自 dist/ui/reading_room.ui.js
   ```

   用 zip 打包，扩展名改成 `.toolpkg` 就是成品。

## 几个坑

- **不要写目录项**（zip 里不要出现 `ui/` 这种单独的条目），只能装上的包都是纯文件。
- **改了包名要改两处**：`src/main.ts` 里的 `TOOLPKG_ID` 和 `manifest.json` 里的 `toolpkg_id`，必须一致。
- **改了界面要重启 Operit**：侧边栏注册带了 `keepAlive`，界面会缓存在内存里。
- `manifest.json` **不要加没验证过的字段**——多一个未知键就可能整包解析失败，报错还只有一句"解析失败"。
