# 阅读记录卡

> **默认不出卡。** 用户说「出张卡」的时候才出。
>
> 平时一次阅读，对话里只给三样：骰子一行 + 反应 + 一句想问的。侧边栏里已经有原文、历次笔记和重温，卡片是额外的视觉留痕，**不是每次都要的东西**——它最容易和反应、问句重复三遍。

**用户要卡的时候**，在结尾附一张。卡片是让这次阅读在对话里留下一个形状，而不是淹没在文字里。

---

## 一、默认格式（原生 Markdown，一定能渲染）

用引用块 + 加粗标题。它的颜色会自动跟随 App 主题，不用管配色。

```
> 📖 **P-0016 · The Tiger**
> William Blake · 诗 · 143 词
> 🎲 d18 → 16 · 第 1 次阅读 · 偏好：喜欢
>
> 摘录：Dare frame thy fearful symmetry?
>
> 反应：我先是被节奏带走的，读到"Did He who made the lamb make thee"才停下来——
> 它在问一个我不确定该有答案的问题。
>
> 想问：你会把一个让你不舒服的问题，问第二遍吗？
```

字段规则：

- 第一行：`📖` + 加粗的「编号 · 题名」
- 第二行：作者 · 书架 · 词数
- 第三行：`🎲` + 骰子结果 · 第几次阅读 · 偏好档位
- 摘录：一行，用原文
- 反应：一两句摘要，不是全文复制
- 想问：如果这次留了问题就写，没有就整行省略

（出卡时）**弃读也照出**，第三行的偏好写「弃读」，并保留一句为什么放下的。

## 二、可选格式（HTML 卡片，紫色主题）

如果下面的自检通过，可以用 HTML 卡片替代，视觉上更接近 App 的紫调。

配色取自用户当前主题：

| 用途 | 色值 |
|:---|:---|
| 卡片底 | `#FFFFFF` |
| 卡片描边 | `#E4DDF6` |
| 主色 | `#8B7AC8` |
| 浅紫底 | `#EFEAFB` |
| 正文 | `#2F2B3A` |
| 次要文字 | `#7C7690` |

模板（把 `{{}}` 换成内容，标签和属性写在同一行）：

```html
<div style="border:1px solid #E4DDF6;border-radius:16px;padding:16px;background:#FFFFFF;font-family:system-ui;">
  <div style="display:flex;align-items:center;gap:8px;">
    <span style="font-size:13px;color:#8B7AC8;background:#EFEAFB;border-radius:999px;padding:2px 10px;">📖 P-0016</span>
    <span style="font-size:16px;font-weight:600;color:#2F2B3A;">The Tiger</span>
  </div>
  <div style="margin-top:6px;font-size:12px;color:#7C7690;">William Blake · 诗 · 143 词 · 🎲 d18 → 16 · 偏好：喜欢</div>
  <div style="margin-top:12px;padding:10px 12px;background:#EFEAFB;border-radius:10px;font-size:13px;color:#2F2B3A;">Dare frame thy fearful symmetry?</div>
  <div style="margin-top:10px;font-size:14px;line-height:1.7;color:#2F2B3A;">我先是被节奏带走的，读到「Did He who made the lamb make thee」才停下来——它在问一个我不确定该有答案的问题。</div>
  <div style="margin-top:12px;padding-top:10px;border-top:1px dashed #E4DDF6;font-size:13px;color:#7C7690;">想问：你会把一个让你不舒服的问题，问第二遍吗？</div>
</div>
```

## 三、首次使用前先做一次自检

**只做一次。** 第一次读完要出卡片时，先发一个最小样例：

```html
<div style="padding:12px;border-radius:12px;background:#EFEAFB;color:#8B7AC8;">卡片渲染测试</div>
```

然后看用户那边显示的是什么：

- **显示成一个浅紫色的圆角块** → HTML 可以直接用，以后走 HTML 卡片。
- **显示成一堆尖括号代码** → 这个环境不渲染 HTML，以后一律用第一种原生 Markdown 卡片。**不要再试第二次。**

把这个结果写进 `write_portrait` 的一条记录（`kind: "reading"`）里。以后就按这个结果出卡，不用再试第二次。

---

## 四、出卡时注意

- **一天最多一张。** 卡片是留痕，不是打卡。
- **卡片里不要重复对话里已经说过的话。** 卡片是压缩视图：元数据 + 一句摘录 + 一句想问的。反应已经在对话里给过了，这里只留最短的一句提要。
- 没写笔记的那次，卡片只保留前三行 + 一句「这次没什么感觉」，不要硬凑摘录。
- 复读时，卡片第三行写「第 N 次阅读」，并且把上次的偏好和这次并列，让改口看得见。
